# 🤖 CodePilot AI

> An autonomous AI software engineering assistant that understands repositories, plans implementations, generates production-ready code, and automatically applies modifications using Large Language Models.

---

## ✨ Features

- 🔍 Repository Analysis
- 🧠 Intelligent Planning
- 📖 Context-Aware Repository Reading
- 💻 AI Code Generation
- ✅ Validation Pipeline
- 📦 Dependency Management
- 🧪 Test Runner
- ⚡ Automatic Code Execution
- 📝 AI Implementation Summaries

## 🚀 Quick Start

### Install dependencies

```bash
pip install -r requirements.txt
```

### Configure environment

```bash
cp .env.example .env
```

Add your Cerebras API key to the `.env` file.

### Start the agent

```bash
python agent.py
```
